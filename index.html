Sample: Quick Recon & Triage Cheat Sheet

A few commands I reach for constantly during the recon and initial-triage phase of an engagement or lab:

# Quick host discovery across a subnet
nmap -sn 192.168.1.0/24

# Full port scan with service and script detection
nmap -sV -sC -p- -oN full_scan.txt target.com

# Pull recent failed logon events for triage (Windows)
Get-WinEvent -FilterHashtable @{LogName='Security'; ID=4625} -MaxEvents 50

# Quick tail of auth logs on a Linux host
tail -f /var/log/auth.log | grep -i "failed\|invalid"

Tip: always get proper authorization before scanning or testing any network or system that isn't yours.
